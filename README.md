# 运动提醒 Exercise Reminder

到点全屏弹出运动视频，**不播完不让关**。专治久坐不动。

Windows 桌面小工具，**零依赖** —— 不需要装 Python、Node.js 或任何运行库，双击即用。

---

## 它解决什么问题

久坐的人都知道该起来动动，但就是不动。

这个工具的逻辑很简单：到了你设定的时间，屏幕直接被运动视频占满。想关掉？等视频播完。

不是弹个通知让你点"稍后提醒"，是实实在在把屏幕接管几分钟。

---

## 特性

- **全屏强制播放** —— 拦截 Esc、Alt+F4、关闭按钮，播完才允许关
- **每天多时段** —— 时间点一行一个，想填几个填几个，支持不均匀
- **自由选片** —— 勾选要播的视频，拖动调整播放顺序
- **暂停但不放纵** —— 空格键或按钮暂停，超过设定时长自动继续
- **紧急出口** —— 按住 Esc 60 秒强制退出，防卡死
- **便携** —— 整个文件夹放哪都能跑，配置跟着走

---

## 快速开始

```
1. 下载 / 克隆本仓库到任意文件夹（比如 D:\运动提醒）
2. 把 mp4 视频丢进 videos 文件夹
3. 双击「开始运动.cmd」
4. 设置时间点，点「保存并应用定时」
```

就这样，没有安装步骤。

## 常见问题

**杀毒软件报警？**
正常。这个工具需要「绕过 PowerShell 执行策略」和「注册计划任务」，这两个行为模式在杀软眼里和恶意软件重合。源码全部公开，可以自己看。不放心的加白名单或用完删掉。

**为什么关不掉？**
这是设计目的。如果真想退出，按住 Esc 60 秒。这是为了防止某个视频文件损坏导致卡死。

**会收集数据吗？**
不会。纯本地运行，不联网，不写注册表（除了计划任务）。
